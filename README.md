# 📊 Superstore Sales Analysis

## 📌 Project Overview
This project focuses on analyzing Superstore sales data to identify business trends, evaluate sales performance, and generate actionable insights.

The project uses Excel, SQL, and Power BI to explore data, perform analysis, and create an interactive dashboard.

## 🎯 Business Objectives
- Analyze overall sales and profit performance.
- Identify top-performing products and categories.
- Understand regional sales performance.
- Analyze monthly and yearly sales trends.
- Identify business opportunities and areas for improvement.

## 🛠️ Tools & Technologies
- **Microsoft Excel:** Data cleaning, Pivot Tables, charts, and dashboard creation.
- **PostgreSQL:** Data analysis using SQL queries, joins, subqueries, CTEs, and window functions.
- **Power BI:** Interactive dashboard and data visualization.
